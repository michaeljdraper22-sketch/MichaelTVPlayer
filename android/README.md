# MichaelTV for Android

An Android port of the Windows app **MichaelTVPlayer** (v1). The entire
Stremio + Xtream logic is shared verbatim with the desktop app: the
pure-Python core (`stremio.py`, `xtream.py`, `models.py`) is copied
byte-identically from `../src` into `michaeltv_core/` by
`prepare_core.py`, and the Kivy UI in `mv/` only drives it. Same search,
same stream ranking, same provider behavior.

## v1 feature set

- **Search** movies and series (Cinemeta catalog) with poster, year and
  type in the results list.
- **Series detail**: season picker + episode list (from Cinemeta's
  episode metadata), or straight to streams for movies.
- **Streams**: every configured Stremio addon is queried (e.g.
  torrentio), results are ranked with the desktop app's exact ordering
  (English preference → resolution preference → size demote → addon
  priority → seeders).
- **Player**: in-app Kivy Video with play/pause, position slider, time
  labels; the screen is kept awake during playback; links are probed
  (1-byte range GET) before playback so dead links are reported
  immediately.
- **Live TV**: Xtream provider categories + channel zap (direct
  mpegts URLs).
- **Settings**: addon URL list (priority order), resolution preference
  (match / auto / 2160 / 1440 / 1080 / 720 / 480), size demote GB,
  Xtream server/user/password. Stored as `settings.json` in the app's
  private data dir.

## v1 limits — read this before wondering where a stream went

**Plain torrent streams cannot play on Android v1.** Entries that are
just an `infoHash` (+ file index) are greyed out with the note
"needs debrid-enabled addon URL (torrent entries can't play on Android
v1)". On the desktop those entries play through the *local Stremio
streaming server* (which downloads the torrent and serves it over
HTTP) — that server doesn't exist on Android.

**Direct URLs play fine** — that includes every stream a debrid service
resolves. To make torrent streams playable:

1. Open your Stremio-compatible addon configurator in a browser — e.g.
   <https://torrentio.strem.fun> (or debridio / mediafusion etc.).
2. Sign in with your debrid account (RealDebrid, AllDebrid, Premiumize,
   debrid.link…) and pick your usual quality options.
3. "Install" the addon — the page shows a **personal addon URL** that
   embeds your debrid key.
4. Paste that URL into MichaelTV ▸ Settings ▸ Stream addons (replace
   or keep the plain torrentio line; the first entry wins ties).

With a debrid-keyed addon URL configured, torrents come back as direct
resolved links, which rank and play exactly like on the desktop.

## Building

### GitHub Actions (recommended)

The repo's CI workflow builds the APK: it runs
`python android/prepare_core.py`, clones a pinned python-for-android,
`sed`-replaces the `P4A_SOURCE_DIR_PLACEHOLDER` token inside
`android/buildozer.spec` with that checkout, and runs `buildozer`.
Download the unsigned-debug APK from the run's artifacts (or the
release, if attached).

### Locally (Linux/WSL; buildozer does not run on Windows)

```bash
cd android
python prepare_core.py            # sync ../src core + stamp version
pip install buildozer cython
# point the spec at a python-for-android checkout (or comment the line
# out and set p4a.branch instead)
sed -i "s|P4A_SOURCE_DIR_PLACEHOLDER|/path/to/python-for-android|" buildozer.spec
buildozer android debug           # APK lands in android/bin/
```

`prepare_core.py` is stdlib-only and runs on Windows and Linux; it
copies `stremio.py`/`xtream.py`/`models.py` from `../src` byte-identical
into `michaeltv_core/`, rewrites the spec's `version`/`android.
numeric_version` from `src/config.py`'s `APP_VERSION`, and byte-compiles
the result (fails the build on any error). Re-run it after every change
to the shared core.

## Sideload

1. Copy the APK (`android/bin/MichaelTV-*.apk`) to the device.
2. Settings ▸ Apps ▸ Special access ▸ *Install unknown apps* — allow it
   for the app you open the APK with (Files, Chrome…), or enable
   developer mode + USB debugging and `adb install MichaelTV-*.apk`.
3. Open MichaelTV, add addon URLs / Xtream credentials in Settings.

## Repo layout

```
android/
  main.py            Kivy app entry (screens wiring, navigation)
  mv/                UI package: settings, home, detail, streams,
                     player, live TV, settings screens
  michaeltv_core/    GENERATED by prepare_core.py (gitignored) —
                     verbatim copy of the Windows app's src/ core
  prepare_core.py    core sync + version stamping
  buildozer.spec     build config (CI replaces P4A_SOURCE_DIR_PLACEHOLDER)
  icon.png           copy of ../assets/icon.png
```
